# My Technical Writing Portfolio

A collection of technical content focused on AI, LLMs, retrieval-augmented generation (RAG), developer tools, APIs, and technical product education.

## About

This portfolio demonstrates my ability to research complex technical subjects and turn them into clear, accurate, developer-focused content.

The pieces in this repository cover:

- Technical explainers
- Developer tutorials
- RAG and LLM concepts
- API and integration guides
- Technical comparisons
- Product documentation
- AI and developer-focused content

## Writing approach

My approach to technical content is simple:

- Be accurate.
- Explain concepts clearly.
- Prioritize practical usefulness.
- Avoid unnecessary jargon.
- Verify technical claims.
- Write for the reader's actual problem.
